Sure! Here are **5 multiple-choice HTML questions**, each with an answer.

1. **What tag is used to define the document type and HTML version?**  
   A) `<doctype>`  
   B) `<document>`  
   C) `<!DOCTYPE html>`  
   D) `<!TYPE html>`  
   **Answer:** C

2. **Which element creates a hyperlink?**  
   A) `<link>`  
   B) `<a>`  
   C) `<href>`  
   D) `<navigate>`  
   **Answer:** B

3. **What is the main purpose of the `<meta>` tag?**  
   A) Display text on the page  
   B) Create a button  
   C) Provide metadata about the HTML document  
   D) Add a table  
   **Answer:** C

4. **Which element is used to insert an image?**  
   A) `<picture>`  
   B) `<img>`  
   C) `<image>`  
   D) `<src>`  
   **Answer:** B

5. **How do you add inline CSS styling to an element?**  
   A) Using the `class` attribute  
   B) Using the `style` attribute  
   C) Using the `css` tag  
   D) Using the `script` tag  
   **Answer:** B
